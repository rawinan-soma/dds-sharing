Design work that is not a route

#44 · §17.5

Password change + retention notice

Current password plus a fresh TOTP. Rules shown before typing, and the 20-character ceiling stated plainly — a password manager will silently generate past it.

 #45 · §10.5

T-5-minute session warning

Bottom-left toast. Not a modal, not a banner, and it does not auto-dismiss — the thing it warns about does not go away.

 #42 · #47 · §15.3

Scheduler-stopped banner

Amber, not red: automatic processing having stopped is not the service being down. States what the stall means for the Reviewer's work, never an error code.

 #52 · #53 · §10.6

Alerts · Re-run · Resend

An Alert is cleared only by naming an outcome from a closed set. Radio buttons, never a text box.

The four emails · #50 · §11

Tables and inline styles only — no Tailwind and no DaisyUI. Outlook renders through the Word engine, which supports neither an external stylesheet nor a class selector it can rely on. Full reasoning in emails/_shared-notes.md.

Typography — Noto Sans Thai, loopless

The specimens below are Thai because that is what the product is set in; the labels are English because this page is documentation. Noto Sans Thai's own glyph box is ascent 1061 + descent 450 = 1.511 em, which is where the 1.55 line-height floor comes from and why Tailwind's defaults (1.33–1.56) are all overridden.
