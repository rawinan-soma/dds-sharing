# prototypes/

Runnable design artefacts, checked into git rather than linked from a design
tool — an agent building [#43](https://github.com/rawinan-soma/dds-sharing/issues/43)
or [#47](https://github.com/rawinan-soma/dds-sharing/issues/47) needs something
it can open, and a Figma link rots.

- **`dds-sharing-ui/`** — the visual design for all seven routes, the non-route
  surfaces and the four Thai emails. Settled by
  [ADR 0009](../docs/adr/0009-the-visual-layer.md); supplies the wireframe that
  is an acceptance criterion of
  [#38](https://github.com/rawinan-soma/dds-sharing/issues/38).

Structure, ordering and copy are **normative** and come from the spec.
Appearance is settled by ADR 0009. Fake data in any prototype is fake.
